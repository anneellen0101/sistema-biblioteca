# Sistema de Biblioteca

## Sobre o projeto

O Sistema de Biblioteca tem como objetivo facilitar o controle de livros,
usuários, empréstimos e devoluções.

## Objetivo

Desenvolver uma solução para organizar o acervo da biblioteca e controlar
os empréstimos e devoluções.

## Público-alvo

- Bibliotecários
- Funcionários
- Alunos

## Funcionalidades

- Cadastro de livros
- Cadastro de usuários
- Consulta de livros
- Empréstimo de livros
- Devolução de livros
- Relatórios
