# Regras de Negócio

## RN01 — Usuário cadastrado

Somente usuários cadastrados poderão realizar empréstimos.

## RN02 — Livro disponível

Somente livros disponíveis poderão ser emprestados.

## RN03 — Usuário em atraso

Um usuário que possuir livro em atraso não poderá realizar um novo empréstimo.

## RN04 — Devolução

Ao registrar a devolução, o livro deverá voltar a ficar disponível.

## RN05 — Empréstimo

Cada empréstimo deverá estar associado a um usuário e a um livro.

## RN06 — Livro emprestado

Um livro que estiver emprestado não poderá ser emprestado novamente.
