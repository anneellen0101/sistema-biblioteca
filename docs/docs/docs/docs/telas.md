# Telas do Sistema

## Tela de Login

A tela de login permite que usuários cadastrados acessem o sistema.

## Tela Inicial

A tela inicial apresenta as principais funcionalidades do sistema.

## Tela de Cadastro de Livros

Permite cadastrar, consultar, alterar e excluir livros.

## Tela de Cadastro de Usuários

Permite cadastrar e consultar os usuários da biblioteca.

## Tela de Empréstimos

Permite registrar e consultar os empréstimos realizados.

## Tela de Devoluções

Permite registrar a devolução dos livros emprestados.

## Imagens das Telas

As imagens das telas do sistema serão apresentadas nesta documentação.
