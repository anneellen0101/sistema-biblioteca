# Testes do Sistema

## Teste 01 — Login

**Objetivo:** verificar se o usuário consegue acessar o sistema.

**Resultado esperado:** o usuário cadastrado consegue entrar no sistema.

## Teste 02 — Cadastro de Livro

**Objetivo:** verificar o cadastro de livros.

**Resultado esperado:** o livro é cadastrado corretamente.

## Teste 03 — Consulta de Livro

**Objetivo:** verificar a consulta de livros.

**Resultado esperado:** o sistema apresenta os livros cadastrados.

## Teste 04 — Empréstimo

**Objetivo:** verificar o registro de empréstimos.

**Resultado esperado:** o empréstimo é registrado quando o livro está disponível.

## Teste 05 — Devolução

**Objetivo:** verificar o registro de devoluções.

**Resultado esperado:** o livro volta a ficar disponível.

## Teste 06 — Usuário em atraso

**Objetivo:** verificar a regra de empréstimo para usuários em atraso.

**Resultado esperado:** o sistema impede um novo empréstimo.
