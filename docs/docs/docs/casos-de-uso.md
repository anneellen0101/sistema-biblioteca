# Casos de Uso

## Atores

- Administrador
- Bibliotecário
- Aluno

## Casos de Uso

### Administrador

- Cadastrar usuários
- Alterar usuários
- Excluir usuários

### Bibliotecário

- Cadastrar livros
- Consultar livros
- Registrar empréstimos
- Registrar devoluções
- Gerar relatórios

### Aluno

- Fazer login
- Consultar livros
- Consultar seus empréstimos
- Solicitar empréstimo
